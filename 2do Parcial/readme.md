# 2do Parcial

Esta carpeta almacena los proyectos desarrollados durante el segundo parcial de la materia. A diferencia de las etapas previas, en esta fase los proyectos comienzan a contar con su propia subestructura debido a la complejidad de las librerías empleadas, como `pandas` y componentes visuales avanzados (`customtkinter`).

## Proyectos Disponibles

1. **[Análisis de Datos con Netflix](./Proyecto_Netflix/)**  
   Aplicación de escritorio conectada a un conjunto de datos (.csv) masivo. Incluye:
   - Pantalla de Login conectada a archivos locales
   - Consultas complejas de minería de datos usando librerías científicas 
   - Tablas dinámicas y visores que justifican propósitos de negocio
   
   *(Para leer las instrucciones detalladas de ejecución, ingresa y lee su `readme` correspondiente).*
