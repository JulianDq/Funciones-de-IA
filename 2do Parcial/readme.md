# 2do Parcial

Esta carpeta almacena los proyectos desarrollados durante el segundo parcial de la materia. A diferencia de las etapas previas, en esta fase los proyectos comienzan a contar con su propia subestructura debido a la complejidad de las librerías empleadas, como `pandas` y componentes visuales avanzados (`customtkinter`).

## Proyectos Disponibles

1. **[Análisis de Datos con Netflix](./Proyecto_Netflix/)**  
   Aplicación de escritorio conectada a un conjunto de datos (.csv) masivo. Incluye:
   - Pantalla de Login conectada a archivos locales
   - Consultas complejas de minería de datos usando librerías científicas 
   - Tablas dinámicas y visores que justifican propósitos de negocio
   
2. **[Gráfica Línea Recta](./Grafica%20linea%20recta/)**
   - Lógica en Python dedicada al cálculo y visualización de la ecuación de la recta de manera matemática.
   
3. **[Examen Práctico](./Examen%20Practico/)**
   - **Arquitectura de Cero Monolitos:** Proyecto moderno dividido estrictamente en Backend (`FastAPI`, `Pandas`) y Frontend (`HTML`, `JS`, `Chart.js`).
   - Calcula medidas de tendencia central (media, mediana, moda) y distribuciones (frecuencias absolutas, relativas, acumuladas, polígono de frecuencias) sobre un dataset real de *Amazon Bestsellers*.
   - Totalmente preparado para despliegue independiente (Hosteable en plataformas como Render).

*(Para leer las instrucciones detalladas de ejecución de los proyectos, ingresa a su respectiva carpeta).*
