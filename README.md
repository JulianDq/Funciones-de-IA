# Funciones-de-IA

Repositorio para la materia / proyectos de Inteligencia Artificial.

## Contenido

* [**1er Parcial**](./1er%20Parcial/readme.md): Sistema de 10 ejercicios en Python desarrollados con interfaz gráfica (Tkinter). Incluye módulos de validación, cálculos condicionales, sumas acumuladas y boletas de pago.
* [**2do Parcial**](./2do%20Parcial/readme.md): Incluye tres proyectos avanzados, destacando una aplicación de minería de datos con Netflix (usando Pandas y CustomTkinter), programación gráfica de línea recta, y un Examen Práctico estructurado bajo una arquitectura de "Cero Monolitos" con FastAPI y Chart.js para calcular distribuciones estadísticas sobre el dataset de Amazon.
