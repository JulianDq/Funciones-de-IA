# Funciones-de-IA

Repositorio para la materia / proyectos de Inteligencia Artificial.

## Contenido

* [**1er Parcial**](./1er%20Parcial/readme.md): Sistema de 10 ejercicios en Python desarrollados con interfaz gráfica (Tkinter). Incluye módulos de validación, cálculos condicionales, sumas acumuladas y boletas de pago.
* [**2do Parcial**](./2do%20Parcial/readme.md): Aplicación avanzada implementada con `CustomTkinter` y `pandas`. Lee, limpia y ejecuta 10 consultas de minería de datos sobre el set de CSV de Netflix. Presenta un visor interactivo y despliega justificaciones de negocio de los datos mostrados en tablas dinámicas.
